\begin{frame}\frametitle{Pourquoi ce cours aujourd'hui ?}
   \begin{itemize}
      \item \textbf{Le constat :} Vos jeux de données sont de plus en plus complexes (Big Data, High-Dim). Excel ne suffit plus.
      \item \textbf{L'enjeu académique :} Une visualisation médiocre peut tuer un papier excellent. Une visualisation interactive peut faire décoller une citation.
      \item \textbf{La révolution 2026 :}
      \begin{itemize}
          \item Fini le temps perdu à "debugger" des axes matplotlib.
          \item L'IA (LLM) génère le code, vous gérez la \textbf{logique visuelle}.
          \item Passage du graphique statique (PDF) à l'application web (Streamlit).
      \end{itemize}
   \end{itemize}
   % Idée image : Un graphique moche "Excel 97" vs un Dashboard moderne
\end{frame}

% SLIDE 4 : Pourquoi le code ? (Argument reproductibilité)
%------------------------------------------------------------------------------
\begin{frame}\frametitle{Pourquoi passer par le code (Python) ?}
   Contrairement aux outils "Click-button" (Excel, Tableau...), le code assure la \textbf{Reproductibilité Scientifique}.

   \begin{itemize}
      \item \textbf{Traçabilité :} Chaque transformation de la donnée est écrite.
      \item \textbf{Scalabilité :} Refaire le graphique avec 1 million de nouvelles lignes prend 1 seconde.
      \item \textbf{Flexibilité :} On n'est pas limité par les menus du logiciel. Si on peut l'imaginer, on peut le coder (ou demander à l'IA de le faire).
   \end{itemize}
\end{frame}
